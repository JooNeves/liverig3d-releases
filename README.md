# LiveRig3D — versões / releases

**PT** — Este repositório guarda as versões do LiveRig3D e o ficheiro `update.json`, que a app lê para saber se há uma versão nova. Cada pacote vai assinado; a app só instala pacotes com assinatura válida. Para usar a app é preciso uma licença.

- `update.json` — a versão mais recente e o pacote de cada sistema.
- `windows/LiveRig3D-windows.zip` — a versão mais recente para Windows (o link fica sempre o mesmo):
  https://github.com/JooNeves/liverig3d-releases/raw/main/windows/LiveRig3D-windows.zip
- `mac/LiveRig3D-mac.dmg` — a versão mais recente para Mac (o link fica sempre o mesmo; a primeira vez abre-se com botão direito ▸ Abrir):
  https://github.com/JooNeves/liverig3d-releases/raw/main/mac/LiveRig3D-mac.dmg

**EN** — This repository holds the LiveRig3D releases and the `update.json` file the app reads to check for a new version. Every package is signed; the app only installs packages with a valid signature. A licence is required to use the app.

- `update.json` — the latest version and the package for each system.
- `windows/LiveRig3D-windows.zip` — the latest Windows version (the link never changes):
  https://github.com/JooNeves/liverig3d-releases/raw/main/windows/LiveRig3D-windows.zip
- `mac/LiveRig3D-mac.dmg` — the latest Mac version (the link never changes; the first time open it with right-click ▸ Open):
  https://github.com/JooNeves/liverig3d-releases/raw/main/mac/LiveRig3D-mac.dmg
